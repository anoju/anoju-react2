- 2026-05-17: 플로팅 메뉴는 `홈`, `전체메뉴`, `playground`, `Scene`, `마이페이지/로그인` 등 주요 목적지에서 기본 노출하고, 자유게시판/Pics 하위 콘텐츠 화면에서는 기본 미노출합니다.
- 2026-05-17: 자유게시판은 모바일 리스트형 목록, 상세, 작성, 댓글을 1차 구현합니다.

- 2026-05-17: 경로 상수, 라우트, 플로팅 메뉴, 전체메뉴 항목을 기준에 맞게 변경했습니다.
- 2026-05-17: `playground`, `Snaps`, 자유게시판, Pics 화면 1차 구현과 모바일 스타일을 추가했습니다.
- 2026-05-17: PocketBase SDK 자동 요청 취소가 React 개발 모드 effect 재실행과 충돌하지 않도록 목록/상세 조회에 `$autoCancel: false`를 적용했습니다.
- 2026-05-17: `npm run build`, `npm run lint` 통과. 브라우저에서 홈/서브 메인/자유게시판/Pics 주요 화면 렌더링과 플로팅 메뉴 노출 정책을 확인했습니다.
